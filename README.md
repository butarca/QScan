# QScan

Android aplikacija za skladišče: skeniraš QR-kodo na paketu in vidiš, kaj moraš narediti s paketom. Seminarska naloga pri predmetu Elektronsko in mobilno poslovanje (FRI 2026/27). Avtorja sta Tilen Butara in Luka Ažman.

Specifikacija: [docs/SPECIFIKACIJA.md](docs/SPECIFIKACIJA.md)

## Zagon

Potrebuješ napravo z Androidom 7.0 ali novejšim in Google Play storitvami.

```
./gradlew :app:installDebug
./gradlew :app:testDebugUnitTest
```

Testne QR-kode so v [docs/test-qr/](docs/test-qr/).
